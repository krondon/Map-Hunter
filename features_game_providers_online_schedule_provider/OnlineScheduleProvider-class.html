OnlineScheduleProvider

OnlineScheduleProvider class

Provider that exposes the next automated online event time based on the online_automation_config stored in app_config.

Supports two modes:

  • automatic: next event = last event + interval_minutes + pending_wait_minutes. Since we don't know the last event time here, nextEventTime is null and the UI should rely on existing pending events from EventProvider.
  • scheduled: next event = next occurrence in scheduledHours (UTC). This is fully computable client-side.
